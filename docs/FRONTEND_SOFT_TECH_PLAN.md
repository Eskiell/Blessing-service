# PR 20 — Redesign soft-tech do frontend

## Objetivo

Evoluir a interface do Blessing para uma identidade tecnológica mais calma,
clara e sofisticada, preservando integralmente o comportamento já validado.

## Escopo

- [x] Definir tokens de cor, superfícies, bordas e sombras soft-tech.
- [x] Redesenhar cabeçalho, conexão, painel do jogo e estatísticas.
- [x] Redesenhar lista, switches, botões e estados de feedback.
- [x] Reduzir brilho, saturação, gradientes intensos e contraste agressivo.
- [x] Adicionar layouts responsivos para desktop, tablet e celular.
- [x] Respeitar a preferência de redução de movimento.
- [x] Preservar componente Vue, chamadas HTTP e comportamento dos cheats.
- [ ] Validar visualmente no navegador do PS5.

## Fora do escopo

- Mudanças na API ou no backend.
- Mudanças nos parsers, formatos de cheat ou acesso à memória.
- Novas funcionalidades ou dependências de frontend.

## Critério de conclusão

O frontend deve continuar operando com o mesmo contrato e apresentar uma
estética soft-tech consistente, legível e responsiva, sem depender da rede.
